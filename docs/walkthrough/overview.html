01 · The problem

Fixing a shot costs a reshoot — or it costs the footage.

Before any software: this is the corner professional filmmakers are already painted into.

💸

A reshoot is a budget line

Crew, location, cast — booked all over again for one shot that didn't work.

📅

And a schedule you don't have

Locations release. Actors move on. Most of the time the calendar simply says no.

🔒

The footage is legally sensitive

Unreleased, and full of real people's faces — the most guarded asset a production owns.

✨

Meanwhile, generative AI can already do what no reshoot can

Re-angle a shot nobody filmed. Change what happened inside it. Add someone who was never on set — things no reshoot budget could buy at any price.

☁️

…and every one of those tools lives in the cloud

Which is the one place unreleased footage legally cannot go. Studios can't upload it, so the tools stay out of reach.

The capability exists. The people who need it most cannot touch it.

04 · What it's actually made of

Two files you can read on stage.

The two claims that matter most — every face is accounted for and nothing leaves the building — are not architecture diagrams. They're a database collection and a network policy.

🍃 MongoDB — running on the box

The consent registry is a Mongo collection called people, bound to localhost. Every person the ingest pipeline detects becomes a document, and the pre-GPU cast gate reads it before any generation is allowed to start.

🏷 policy — approved · unknown · remove
📝 consent — record URL, scope, notice / signed / revoked dates
🧬 faceEmbeddings — plain arrays, cosine-matched in numpy — no vector service

🔒 NemoClaw — the egress policy

NVIDIA's agent stack: the OpenClaw harness runs inside an OpenShell sandbox. What the agent may reach is a declarative file, not a promise — first match wins:

allow  tcp 127.0.0.1:8000   # our backend — every tool call
allow  tcp 127.0.0.1:11434  # the local model (Ollama)
deny   udp 53               # DNS — the first packet of any phone-home
deny   tcp 53
default: deny
05 · The agent's manners

Permission, tiered by reversibility.

The agent is helpful, not headstrong. What it's allowed to do depends on how easily it can be taken back.

TIER 1

Small & reversible

It just does it.

Looking things up, tidying names — anything trivial to reverse.

TIER 2

Real edits

It proposes — you apply.

The agent drafts the change, you preview it, and it lands as one undo step.

TIER 3

Generative & expensive

Plan first. Runs on approval.

It must show which references, which model, and how long — before anything runs.

Nothing the agent does can bypass the human.
06 · The differentiator

The consent registry.

The feature we protect above all others: every face on screen is accounted for — foreground or deep background, real or generated.

👁️

Every person is detected

Each face in the footage is found, matched into an identity, and given a status.

Approved cleared to appear
Unknown never silently passed
Remove taken out of the shot
🔁

Output is re-checked

Every generated clip is scanned again before it can land in the cut — an unapproved face cannot ship, even if a model hallucinates one.

⛔

Refused before it starts

Ask for a shot with someone unapproved, and the request is refused before the expensive generation even begins.

🧾

Every generated file carries its receipt

What made it · from what · approved by whom.

We never say guaranteed — professionals know better. We say: Policy-enforcedAuditedHuman-signed-off
